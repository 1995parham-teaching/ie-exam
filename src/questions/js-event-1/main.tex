\قسمت{رویدادها}

سپهر یک برنامه نویس فرانت است، از او در یک مصاحبه خواسته شده است
که تابع \متن‌لاتین{setBgColor}
را که تعریف آن در ادامه آمده است با استفاده از \متن‌سیاه{جاوا اسکریپت}
و \متن‌سیاه{بدون}
تغییر در کد \متن‌لاتین{HTML}
به عنوان یک هندلر روی یک دکمه ثبت کند. آیا این امر ممکن است؟
دقت داشته باشید که این دکمه حتما این تابع را با پارامتر \متن‌لاتین{\متن‌ایتالیک{orange}}
فراخوانی می‌کند.
شما مجاز به نوشتن هر میزان کد جاوا اسکریپت که صلاح می‌دانید هستید.

\begin{latin}
\begin{minted}[]{js}
function setBgColor(color) {
  document.getElementById('change-my-color')
                    .style.backgroundColor = color;
}
\end{minted}
\end{latin}

\نمره{۳}

% پاسخ پیشنهادی است و پیش از استفاده در تصحیح نیاز به بازبینی دارد.
\begin{پاسخ}

بله ممکن است. چون هندلر باید با پارامتر مشخصی فراخوانی شود، تابع را در یک تابع دیگر می‌پیچیم:

\begin{latin}
\begin{minted}[]{js}
document
  .getElementById('change-my-color')
  .addEventListener('click', function () {
    setBgColor('orange');
  });
\end{minted}
\end{latin}

\شروع{فقرات}
\فقره نوشتن \متن‌لاتین{addEventListener('click', setBgColor('orange'))}: نادرست است، چون تابع همان‌جا فراخوانی می‌شود و مقدار بازگشتی‌اش به عنوان هندلر ثبت می‌شود
\فقره استفاده از \متن‌لاتین{onclick} در جاوا اسکریپت هم پذیرفته است
\فقره تغییر \متن‌لاتین{HTML}: بدون نمره، چون در صورت سوال منع شده است
\پایان{فقرات}

\end{پاسخ}
