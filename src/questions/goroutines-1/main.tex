\قسمت{پایان گو روتین‌ها}

خروجی کد زیر چه خواهد بود؟ محتمل‌ترین گزینه را انتخاب کنید و آن را توضیح دهید.

\begin{latin}
\begin{minted}{go}
package main

import "fmt"

func main() {
    go func() {
      fmt.Println("goroutine-2")
    }()

    fmt.Println("goroutine-1")
}
\end{minted}
\end{latin}

\شروع{شمارش}[ا)]

\فقره برنامه تمام نمی‌شود.

\فقره خروجی:

\begin{latin}
\begin{minted}{output}
goroutine-2
goroutine-1
\end{minted}
\end{latin}

\فقره خروجی:

\begin{latin}
\begin{minted}{output}
goroutine-1
goroutine-2
\end{minted}
\end{latin}

\فقره خروجی:

\begin{latin}
\begin{minted}{output}
goroutine-1
\end{minted}
\end{latin}

\پایان{شمارش}

\نمره{۱}

% پاسخ پیشنهادی است و پیش از استفاده در تصحیح نیاز به بازبینی دارد.
\begin{پاسخ}

گزینه‌ی (د): تنها \متن‌لاتین{goroutine-1} چاپ می‌شود.

با پایان یافتن تابع \متن‌لاتین{main} برنامه تمام می‌شود و منتظر گوروتین‌ها نمی‌ماند.
در عمل هم زمانی برای زمان‌بندی گوروتین دوم باقی نمی‌ماند.
برای دیدن هر دو خروجی باید همگام‌سازی داشت، مثلا \متن‌لاتین{sync.WaitGroup} یا یک کانال.

انتخاب گزینه‌ی درست بدون توضیح دلیل، نیمی از نمره را دارد.

\end{پاسخ}
